# 校园导览 Agent PRD

## 一、项目定位

本项目是一个面向复旦校园的 AI 导览 App。用户可以通过校园地图查看不同点位，也可以在游览过程中拍照识别建筑、雕塑、牌匾、展板、道路景观等对象，并获得对应讲解。

产品核心不是传统的静态校园介绍，而是让用户在真实游览过程中“看到什么、拍下什么，就能听到什么”。系统会结合用户当前位置、拍摄内容、校园点位知识库和用户 profile，生成更符合用户兴趣和身份的个性化导览。

## 三、目标用户

主要面向以下用户：

- 新生：希望快速了解校园空间、学习生活和重要地点。
- 访客：希望获得基础校园介绍和游览路线。
- 校友：希望了解校园变化，唤起校园记忆。
- 家长：希望了解学校环境、学生生活和校园文化。
- 交换生 / 国际访客：希望获得中英双语校园讲解。
- 在校学生：希望通过 AI 重新发现熟悉校园里的历史、建筑与故事。

## 四、核心功能

### 1. 校园地图与点位浏览

App 提供校园地图，标注核心导览点位。用户可以点击点位查看基础介绍、推荐停留时长、开放情况和附近推荐。

MVP 阶段可先覆盖 8-10 个核心点位，例如：

- 相辉堂
- 光华楼
- 图书馆
- 三教
- 北区食堂
- 光草
- 操场
- 宿舍区
- 校史相关点位
- 校园景观 / 银杏路等生活化点位

每个点位包含基础信息：

- 点位名称
- 位置
- 类型
- 简短介绍
- 历史 / 文化信息
- 推荐讲解角度
- 适合人群
- 附近点位推荐

### 2. 拍照识图讲解

用户在校园游览时，可以拍摄当前看到的建筑、雕塑、牌匾、展板或景观。系统结合照片内容和当前位置，判断用户正在关注的对象，并调用校园知识库生成讲解。

识别逻辑建议为：

```text
拍照输入 -> 图像识别 -> 获取当前位置 -> 匹配附近候选点位 -> 检索知识库 -> 导览 Agent 生成讲解
```

这样可以降低误识别风险，避免单纯依赖视觉模型胡乱判断。

用户可以追问：

- “这是什么建筑？”
- “这里有什么历史？”
- “这块牌子是什么意思？”
- “附近还有什么值得看？”
- “给我讲得轻松一点。”
- “用更学术的方式讲。”
- “适合小朋友听的版本。”

### 3. 用户 Profile 个性化

用户可以输入或选择自己的 profile，用于调整导览内容。

MVP 可支持以下字段：

- 身份：新生、在校生、访客、校友、家长、交换生、高中生
- 兴趣：校史、建筑、校园生活、人文、自然、拍照、吃饭、运动
- 游览时间：15 分钟、30 分钟、1 小时、半日
- 讲解风格：轻松、有趣、严肃、学术、亲切、适合小朋友
- 语言偏好：中文、英文、中英双语
- 体力偏好：少走路、正常、想多逛

系统根据 profile 生成不同讲解重点。

例如同样是相辉堂：

- 新生：讲开学、毕业、校园仪式感和学生生活。
- 访客：讲基础校史和代表性意义。
- 校友：讲校园记忆和空间变化。
- 建筑爱好者：讲建筑外观、空间位置和校园景观。
- 历史学用户：讲校史脉络和时代背景。

### 4. 导览员 Agent 切换

用户可以选择不同导览员 Agent。不同 Agent 使用同一知识库，但讲解角度、语言风格和信息重点不同。

MVP 可设置 4 个导览员：

- 校史导览员：偏严谨，讲学校历史、人物、事件和制度沿革。
- 新生学长 / 学姐：偏亲切，讲校园生活、上课路线、食堂、自习、日常经验。
- 建筑观察者：偏空间与审美，讲建筑风格、校园布局、景观关系和拍照角度。
- 校园故事收集者：偏轻松，讲校园趣闻、学生记忆、生活细节和地点故事。

用户可以在同一地点切换 Agent，获得不同版本讲解。

### 5. 个性化路线推荐

用户输入身份、兴趣和可用时间后，系统推荐一条适合的校园导览路线。

示例：

- “我是高中生，第一次来复旦，只有 30 分钟。”
  推荐路线：相辉堂 -> 光草 -> 图书馆 -> 北区食堂。
  讲解重点：校园气质、学习生活、公共空间、学生日常。
- “我是校友，十年没回来了，想怀旧。”
  推荐路线：相辉堂 -> 老教学楼 / 图书馆 -> 食堂 -> 光草。
  讲解重点：校园变化、共同记忆、可拍照留念点。
- “我是建筑爱好者，想看校园空间。”
  推荐路线：相辉堂 -> 光华楼 -> 图书馆 -> 光草。
  讲解重点：建筑尺度、空间布局、景观关系。

## 五、知识库建设

导览程序需要建立结构化校园点位知识库，避免模型凭空编造。

每个点位建议包含：

- 基础介绍
- 历史沿革
- 建筑 / 空间特征
- 相关人物与事件
- 校园生活关联
- 趣味故事
- 适合拍摄对象
- 常见问题
- 不同用户版本讲解
- 资料来源或维护备注

每个点位可准备多种讲解版本：

- 30 秒短讲解
- 2 分钟标准讲解
- 校史向讲解
- 建筑向讲解
- 新生向讲解
- 校友怀旧向讲解
- 亲子 / 家长向讲解
- 英文导览版

## 七、核心体验流程

1. 用户首次进入 App，选择身份、兴趣、游览时间和讲解风格。
2. 系统推荐一条校园路线，并显示地图点位。
3. 用户到达某个点位后，可以点击点位查看讲解，也可以拍照识别眼前对象。
4. 系统根据照片、位置、知识库和用户 profile 生成个性化讲解。
5. 用户可以继续追问，或切换不同导览员获得不同讲法。
6. 游览结束后，系统生成本次校园导览记录，包括去过的点位、拍摄识别过的对象、收藏的讲解和推荐后续路线。

## 八、产品价值

- 对新生来说，它可以降低熟悉校园的成本，让校园空间更快变得亲切。
- 对访客和家长来说，它可以提供比静态地图更自然、更有现场感的校园介绍。
- 对校友来说，它可以通过地点讲解和校园变化唤起记忆。
- 对交换生和国际访客来说，它可以提供双语讲解，帮助理解校园文化。
- 对在校学生来说，它可以让熟悉的校园重新变得可探索，让日常经过的地点拥有更多历史、建筑和故事层次。

## 九、一句话总结

复旦校园多模态 AI 导览程序，是一个结合校园地图、拍照识图、点位知识库和个性化导览 Agent 的智能导览 App。用户在校园中看到什么、拍下什么，就能获得符合自己身份、兴趣和游览目的的讲解，从而以更自然、更有现场感的方式理解复旦校园。

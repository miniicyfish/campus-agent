# 复旦大学校史馆

## 基础介绍

复旦大学校史馆位于邯郸校区“复旦源”历史文化遗存区域，前身为1921年建成的奕住堂，是复旦现存最早的保持原貌的建筑[citation:1][citation:15]。这座青瓦白砖、朱砂红色窗格的两层建筑，本身就是一件珍贵文物，被认定为“校内最具中式风格的建筑”[citation:1][citation:3][citation:10]。

2025年百廿校庆前，校史馆作为“一源六馆”的重要组成部分焕新开放，新馆展陈面积达2150平方米，可同时容纳600人参观[citation:7][citation:18]。展览以“教育报国、自立自强”为主线，分8个展区陈列1000余件珍贵校史文物，涵盖存世最早的1909年复旦文凭、孙中山“天下为公”题词、毛主席亲笔题写校名等镇馆之宝[citation:8][citation:14][citation:15]。这里是了解复旦百廿年奋斗历程的必访之地，建筑之美与历史之厚重相得益彰。

## 历史沿革

校史馆所在的建筑经历了从办公楼到图书馆、再到校史馆的功能变迁。

**奕住堂时期（1921-1929）**：1921年，中南银行总经理、爱国华侨黄奕住捐资一万余元建造此楼，故名“奕住堂”[citation:1][citation:5][citation:15]。建筑由毕业于耶鲁大学建筑系的美国建筑师亨利·墨菲设计，最初作为校办公楼，一楼辟出两间作为图书室[citation:1][citation:15]。

**仙舟图书馆时期（1929-1950年代）**：1929年，奕住堂扩建左右两翼，平面由矩形扩展为“H”形结构，改为图书馆。为纪念合作化运动创始人、前教务长薛仙舟教授，更名为“仙舟图书馆”[citation:1][citation:15]。抗战期间，建筑东翼曾被日军炮弹损坏，战后修复[citation:1][citation:15]。

**校史馆时期（2005年至今）**：2005年百年校庆之际，翻修后的奕住堂正式成为复旦大学校史馆对外开放[citation:1][citation:5][citation:6]。2024年7月8日起闭馆进行展陈设备升级与建筑维护[citation:4][citation:21]。2025年5月，作为“复旦源”文化功能区的重要组成部分，校史馆新馆正式启用并向社会公众开放[citation:7][citation:18]。

## 建筑特征

校史馆坐落于“复旦源”核心区，位于邯郸校区本部西部，大草坪南端，相辉堂草坪南侧，临近校医院[citation:12]。建筑东邻相辉堂草坪，与子彬院等历史建筑共同构成校园核心景观群。

**设计者**：由教会大学建筑“宫廷化”倾向的代表人物、毕业于耶鲁大学建筑系的美国建筑师亨利·墨菲设计[citation:1][citation:15]。在奕住堂的设计方案中，墨菲采用混凝土模仿中国古典建筑的木柱子，用铁件制造中国式的花格窗，将中国古典建筑符号运用从屋顶延伸到墙体，使中西合璧式建筑的外部造型特征更加中国化[citation:1][citation:15]。

**外观风格**：采用民族主义的古典复兴式建筑风格，是一座造型优美的宫殿式大屋顶两层砖木建筑[citation:1][citation:15]。房屋两翼小巧玲珑，呈现四面歇山、八角飞檐的建筑形式，整体呈工字型，造型简单而优美[citation:1][citation:15]。外立面通体采用朱砂红色彩，延续建校初期建筑色调特征[citation:1]。沿中轴线对称分布，内部构造雕梁画柱，被认定为“校内最具中式风格建筑”[citation:1][citation:3]。

**内部空间**：2025年焕新后，展陈面积达2150平方米，内部改造既保留铁件花格窗等历史元素，又配置现代化声光展陈系统[citation:1][citation:7][citation:18]。

## 陈列展览

2025年新馆启用后，展览以“自立自强、卓越有趣”为主线，以时间为轴，着力凸显复旦人120年来教育救国、教育报国、教育强国的奋斗历程，完整呈现了复旦大学由私立而公立、由专科而综合、由文理而与医科相融相济，以及迈向世界一流大学的改革创新历程[citation:7][citation:18]。

**展区划分**：以时间为线索分为8个展区——

| 展区 | 时间范围 |
|------|----------|
| 筚路蓝缕 创办公学 | 1905—1917年 |
| 私立名校 冠盖东南 | 1917—1937年 |
| 内迁重庆 国立复旦 | 1937—1949年 |
| 蓄势待发 谱写新篇 | 1949—1956年 |
| 探索前行 勇攀高峰 | 1957—1976年 |
| 改革春雷 激荡奋进 | 1977—1999年 |
| 继往开来 创建一流 | 2000—2014年 |
| 守正创新 奋进新程 | 2014年至今 |

另设有反映新一轮全面深化改革专题展区。展览通过大量珍贵文物、史料、模型、视频等多样化形式呈现[citation:1][citation:8][citation:14]。

## 重要馆藏

校史馆珍藏1000余件珍贵校史文物，核心展品包括[citation:1][citation:8][citation:14]：

**存世最早的复旦毕业文凭**：1909年（宣统元年）颁发给复旦公学第二届毕业生张彝。2005年复旦百年校庆前夕，张彝的孙子、复旦大学校友、知名物理学家张首晟将其捐赠给母校[citation:8][citation:14]。

**孙中山“天下为公”题词**：孙中山先生亲笔题写，赠予曾领导学生参与五四运动的复旦学生会副主席朱承洵[citation:8][citation:14]。

**毛主席亲笔题写校名**：1950年11月，时任复旦校务委员会副主任的陈望道致信恳请毛主席题写校名。1951年下半年，陈望道拜会曾任复旦校务委员会主任的新中国第一任大法官张志让，二人商定请时任最高人民法院副院长的吴溉之再次向毛主席转呈题字请求。很快张志让收到了毛主席的亲笔信函，内附一张没有落款的宣纸题字[citation:8][citation:14]。

**“五四运动”上海第一钟**：与复旦师生参与五四运动相关的珍贵文物[citation:8][citation:14]。

**陈寅恪履历表**：其证明人是中国物候学创始人竺可桢[citation:14]。

**其他重要文物**：中国第一根医用封闭式热电子X光管、第一台601型模拟计算机（电子积分机）、第一台质子加速器，以及1941年重庆北碚战时办学沙盘等场景复原模型[citation:15][citation:18]。

## 教育功能

校史馆承担新生入学教育、校庆主题活动等常态化育人职能，年接待量超过2万人次[citation:2][citation:3][citation:18]。

**新生入学教育**：2023年8月组织新生参访活动，通过孙中山题词匾额等展品解读校史红色基因[citation:2]。

**留学生专场导览**：2023年10月开展留学生专场导览，重点解说李登辉校长推行通才教育等历史事件[citation:3]。

**社会公众开放**：2025年新馆启用后，校史馆成为“复旦源”历史文化功能区的一部分，正式面向社会公众开放，并配备志愿讲解队伍[citation:7][citation:11][citation:18]。

## 趣味故事

**故事一：墨菲的中式营造实验**
设计奕住堂的亨利·墨菲，是教会大学建筑“宫廷化”倾向的代表人物。他曾在雅礼协会、洛克菲勒基金会等机构的委托下，设计了长沙雅礼大学、南京金陵女子大学、北京燕京大学等一系列中国高校建筑。在奕住堂设计中，墨菲大胆尝试用混凝土模仿木柱、用铁件制造花格窗，将中式符号从屋顶延伸到墙体，使这栋建筑成为他探索“中西合璧”风格的早期实验作品[citation:1][citation:15]。

**故事二：“仙舟”变“傻瓜”的误会**
1929年，奕住堂扩建后更名为“仙舟图书馆”，匾额由复旦校友、书法家于右任题写。因草书飘逸，“仙舟”二字远看酷似“傻瓜”，学生们便戏称它为“傻瓜馆”。有学生甚至写对联“宁去傻瓜馆，不入百乐门”明志苦读。这个外号背后，其实是对薛仙舟先生一生利他奉献精神的一种幽默致敬[citation:15]。

**故事三：一封跨越两年的校名题字**
1950年，陈望道致信毛主席恳请题写校名，未得回复。1951年，陈望道与张志让商议后，请吴溉之再次转呈请求。不久张志让收到毛主席亲笔信函，内附一张没有落款的宣纸题字——这就是沿用至今的“复旦大学”校名。为何不落款？据说毛主席谦虚地认为，自己的字“不像书法家写的那样好”[citation:8][citation:14]。

**故事四：张首晟的百年传承**
2005年复旦百年校庆前夕，知名物理学家张首晟将祖父张彝1909年的毕业文凭捐给母校。这张文凭是目前存世最早的复旦文凭，上面有校长高凤谦、监督严复等人的签名盖章。从1909年到2005年，从张彝到张首晟，一张文凭跨越近百年回归复旦，成为校史馆的“镇馆之宝”[citation:8][citation:14]。

## 拍照建议

- **最佳机位**：正面中轴线拍摄可将青瓦飞檐、朱砂红色窗棂完整收入画框，东西两翼对称展开，最显建筑气势；靠近东侧或西侧仰拍，能突出八角飞檐和歇山顶的优美曲线。
- **最佳时间**：晴天上午光线明亮，朱砂红色外立面与蓝天对比鲜明；下午阳光斜射时，赭红色窗格在光影下格外温暖。
- **拍摄细节**：屋檐下的中式花格窗铁件、雕梁画栋的内部装饰、重要馆藏展品的特写都是值得记录的细节。

## 常见问题

### 校史馆和校友馆是同一个地方吗？

不是。两馆曾先后使用同一栋建筑（奕住堂）。2024年校史馆迁至“复旦源”新址（仍在奕住堂建筑内，但为焕新后的展陈空间），奕住堂经修缮后于2025年5月作为校史馆新馆重新开放。校友馆位于另一栋建筑。

### 这里最值得看什么？

最值得看三样：一是建筑本身——复旦现存最早、由亨利·墨菲设计的中西合璧式建筑；二是“镇馆之宝”——1909年最早毕业文凭、孙中山“天下为公”条幅、毛主席题校名手迹；三是8大展区完整呈现的百廿年办学脉络[citation:1][citation:8][citation:14]。

### 校史馆需要预约吗？

2025年新馆启用后已正式向社会公众开放。社会公众可通过“复旦源”小程序预约入校，系统将自动开通邯郸校区北部入校权限[citation:7][citation:18]。

### 这里有什么历史？

前身是1921年建成的奕住堂，1929年扩建后改为仙舟图书馆，2005年百年校庆时辟为校史馆，2025年百廿校庆焕新升级[citation:1][citation:15]。

### 这里适合拍照吗？

非常适合。中西合璧的宫殿式外观极具辨识度，朱砂红墙配青瓦飞檐，是校园经典打卡点之一[citation:1][citation:3][citation:10]。
